# ShilpSetu — SIH 1-Day Prototype

A mobile-first React/Vite prototype based on the uploaded SIH documentation.

## Demo flow
Dashboard → Add Product → Upload Photo → AI Analysis (prototype simulation) → Review/Edit → Price Guidance → Publish → Ranked Market Matches → Opportunity Details → Save/Enquiry → Follow-up.

## Run
```bash
npm install
npm run dev
```
Then open the local URL shown by Vite.

## Important prototype note
The AI analysis is intentionally simulated for the one-day demo. The UI and workflow are designed so the next iteration can connect the AI through a FastAPI backend, keeping provider keys off the client.

## SIH positioning
This is not presented as an Amazon-style marketplace. The central value is AI-assisted catalog readiness + transparent price guidance + explainable market opportunity matching, with artisan approval before publishing/contact.
